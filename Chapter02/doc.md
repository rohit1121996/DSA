# Remove Duplicate from Sorted Array

- Problem statement

- Non decreasing sorted order:

  [1, 2, 4, 8, 12] -> increaseing order
  [12, 9, 8, 7, 5, 1] -> decreasing order

- Sorted and Non Decreasing/Increasing:
  [1, 2, 3, 3, 3, 3, 4, 4, 5, 8, 8, 9]
  - Always may be have duplicatate if sorted and Non Decreasing/Increasing order

- in place: means we don't have to create new we have to change same array or object
